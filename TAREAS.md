## 5. Recordatorios de trabajo

- Cada tarea debe tener una persona responsable y una persona revisora distinta.
- Cada integrante debe ser responsable de al menos una tarea sustantiva de contenido o código y revisar al menos un Pull Request de otra persona.
- Las tareas que dependan de otras solo deben comenzar cuando sus requisitos estén integrados en `main`.
- Realicen los cambios de cada tarea en su rama correspondiente y abran un Pull Request hacia `main`.
- Actualicen este registro con el estado y el enlace del Pull Request. Las modificaciones posteriores de `TAREAS.md` también se realizan mediante ramas y Pull Requests.
- Conserven los enlaces completos y accesibles.
