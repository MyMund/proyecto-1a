Programas de Cálculo Geométrico-Vectorial y Evaluador de Impuestos Tecnológicos mediante Operaciones Lógicas.

Objetivo

Desarrollar aplicaciones en Java que permitan resolver problemas financieros y geométrico-vectoriales mediante la aplicación de lógica proposicional, operaciones matemáticas y algoritmos computacionales.

Problematica

La resolución de problemas financieros y matemáticos requiere analizar diferentes condiciones y realizar operaciones de manera precisa. En el ámbito financiero, es necesario determinar correctamente los porcentajes de impuestos según las características de una compra; mientras que en el ámbito geométrico-vectorial, se requiere calcular desplazamientos y distancias entre puntos de un plano cartesiano. Por ello, se propone desarrollar herramientas informáticas que automaticen estos procedimientos y faciliten la obtención de resultados.

Metodologia

Antes de empezar a program, nos pusimos de acuedo para ver que se iba hacer cada quien. Para resolver este proyecto, primero platicamos sobre el problema y nos organizamos pararesolverlo. Después fuimos armando el programa y probándolo entre todos, hasta quedar conformes con los resultados.

Análisis

Para el programa se necesitaba hacer dos cosas, calcular la distancia entre dos puntos y ayudar a saber la tasa de impuestos aplicarla a una compra . También definimos qué datos le pediriamos a quien lo usara y qué resultados le mostraríamos .

Diseño y Programación

Ya teniendo todo claro , pensamos como resolver cada parte y acodamos los pasos después programamos la solucion en Java y en Python utilizamos variables

Pruebas

Probamos distintos valores y combinaciones mediante diez corridas de escritorio. Así pudimos comprobar los resultados, encontrar posibles errores y hacer ajustes antes de cerrar el proyecto.

Durante todo el Proceso

Cada quien aportó lo que sabía y fuimos revisando juntos cómo avanzaba el trabajo. Así conectamos varias materias y pudimos reunir el proceso y los resultados para el reporte y la exposición.

En pocas palabras:diseñamaos,programamos,probamos y documentamos una solución hecha en equipó
