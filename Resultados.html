Análisis de resultados

Problema 1: Evaluador fiscal

En este ejercicio se creó un programa que calcula el impuesto de una compra. Para saber qué tasa aplicar, se toman en cuenta dos aspectos: si la persona compradora es estudiante acreditada (P) y si el producto pertenece al catálogo educativo (Q). Al final, el impuesto se suma al precio para obtener el total.

Para revisar que el programa respondiera correctamente, se probaron las cuatro combinaciones posibles de P y Q. Se utilizó como ejemplo un precio de $1,000.00:

P Q Tasa aplicada Impuesto Total a pagar
Verdadero Verdadero 0 % $0.00 $1,000.00
Verdadero Falso 8 % $80.00 $1,080.00
Falso Verdadero 8 % $80.00 $1,080.00
Falso Falso 16 % $160.00 $1,160.00

Al revisar los resultados, se observa que cuando se cumplen las dos condiciones no se cobra impuesto. Si solo se cumple una, se aplica el 8 %; y si no se cumple ninguna, se aplica el 16 %. También es importante probar qué sucede si el precio se deja vacío, se escriben letras o se ingresa un valor negativo. En esos casos, el programa debe indicar que el dato no es válido para evitar un resultado incorrecto.

Conclusión del problema 1

Este ejercicio permitió comprobar cómo se pueden usar condiciones para resolver un cálculo de manera automática. Las pruebas muestran que el programa aplica la tasa correspondiente en cada caso y calcula el total correctamente. También se comprobó la importancia de revisar los datos ingresados antes de hacer las operaciones.

Problema 2: Distancia entre dos puntos

En este ejercicio, el programa encuentra la distancia que hay entre dos puntos del plano cartesiano. Primero calcula cuánto cambia la coordenada X y cuánto cambia la coordenada Y. Después utiliza esos resultados en la fórmula de distancia:

Δx = x2 - x1,    Δy = y2 - y1

d = √((Δx)2 + (Δy)2)

Por ejemplo, si el punto inicial es P1 = (0, 0) y el punto final es P2 = (1, 1), el cambio en X es 1 y el cambio en Y también es 1. Al aplicar la fórmula, la distancia es √2, es decir, aproximadamente 1.4142 unidades.

Para revisar el cálculo en otras situaciones, se pueden usar estos casos:

Punto inicial Punto final Δx Δy Distancia
(0, 0) (1, 1) 1 1 1.4142
(-2, 3) (4, -5) 6 -8 10
(2, -1) (2, -1) 0 0 0
(1, 2) (6, 2) 5 0 5

Estos ejemplos sirven para comprobar que la fórmula funciona con coordenadas negativas, cuando los dos puntos son iguales y cuando el movimiento ocurre solamente en uno de los ejes. Si alguna coordenada queda vacía o se escribe algo que no sea un número, el programa debe mostrar un aviso en lugar de intentar calcular la distancia.

Conclusión del problema 2

Con este ejercicio se puso en práctica el cálculo de la distancia entre dos puntos y el uso del teorema de Pitágoras. Los casos de prueba muestran que la fórmula permite obtener el resultado esperado en distintas situaciones. Además, validar las coordenadas ayuda a que el programa no trabaje con datos incompletos o incorrectos.

Conclusión general

Al trabajar en estos dos problemas, se aplicaron en Java tanto condiciones lógicas como fórmulas matemáticas. En el evaluador fiscal, el resultado depende de las características de la compra; en el cálculo de distancia, depende de las coordenadas de los puntos. Las pruebas ayudan a comprobar que cada programa siga las instrucciones y muestran por qué es importante revisar los datos antes de realizar un cálculo.
